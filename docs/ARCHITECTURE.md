# Game architecture

How the game in `game/` works and where to change what. The data it reads is made by the pipelines in
`docs/PIPELINES.md`; the reasons behind most choices are in the working notes, `docs/HISTORY.md` (in the private repository only).

## In 30 seconds

- A *Vampire Survivors*-like made with the assets of the **Dofus Retro** client (Ankama). The player picks one of 15
  Dofus classes (Féca, Osamodas, Enutrof, Sram, Xélor, Ecaflip, Eniripsa, Iop, Crâ, Sadida, Sacrieur, Pandawa,
  Roublard, Brigandin = id `bandit`, Otomaï) and one of 20 zones, and survives 10 minutes of monster waves. Spells cast
  themselves; every level-up offers a choice (spell, weapon, characteristic, fusion…). Bosses, Dofus eggs, relics,
  random events, ToT's quiz, a shop, achievements, Hard and Endless modes. The UI is translated into 7 languages
  (fr, en, de, es, it, nl, pt).
- **Plain JavaScript, no framework, no build step**: serve `game/` with any static server and it runs. Global scripts
  loaded in order by `game/index.html` (no modules). Menus are DOM; runs are drawn with PixiJS (WebGL), with the 2D
  canvas as fallback.
- All game data is in `game/data/content.json`, generated by `tools/make_content.py` — never edit it by hand.

### The extension pattern

`Run` is defined in `game.js`; newer systems live in their own file as `Object.assign(Run.prototype, { … })` and are
**called from hook points** in game.js (e.g. `updateElites()` from `Run.update`). Menus do the same with
`Object.assign(UI, { … })` in a `ui_*.js` file. Put a new run system or a new screen in such a file (an existing one
when it fits, a new one added to `index.html` otherwise), not in `game.js` / `ui.js`, which are already the biggest
files. A new script in `index.html` needs its `?v=` (run `tools/bump_build.py` with the current version to refresh
them all).

## Boot, loop, states

- `Game.boot()` (main.js) loads the save (`Store`), content.json, sprites.json, icons and sounds; applies refunds of
  removed items; reads URL parameters into `Game.debug`; shows `UI.mainMenu()`.
- `Game.state`: `'boot'` → `'menu'` → `'run'`; `UI.modalOpen()` freezes the run (pause, level-up, scenes).
- The loop requests the next frame **first**, then runs `Game.frame()` inside a try/catch: one bad frame never freezes
  the game; the first error is kept in `Game._frameErr` (tests check it stays `null`).
- `Game.startRun()` loads the zone's, class's and effects' sheets, places the camera, plays the `'countdown'`
  cinematic (the run clock is frozen 3.3 s), then the music. `Run.dispose()` frees everything when the run ends.
- `Game.levelUp()` → `Run.upgradeOptions(n)` → `UI.levelUpMenu(R, opts)`; when everything is maxed →
  `UI.levelUpMaxed` (purse or mass potion; its internal kind is still `'bread'`).
- `Run.endRun()` / `Game.runOver()` → `UI.runOverMenu` (grade, numbers, Replay).

## A run (`Run`, game.js)

Main state: `player`, `mobs`, `projs` (player projectiles), `eprojs` (enemy projectiles), `zones`, `slashes`, `beams`,
`cones`, `summons`, `pickups` (ambers, kamas, food, relics, boosters…), `effects`, `particles`, `texts`, `rings`,
`spells` (SpellInst), `weapon` (SpellInst), `passives`, `relics`, `stats`, `time`, `level`, `xp`, `kamas`, `map`,
`world` (`SPR.worlds[...]`), `bounds`, `cam`, `cine`.

- `recompute()` builds `this.stats`: class base × scrolls (`Store.data.scrolls`) × shop characteristics (`passLv`,
  through `passivePer`) × the run's passives × relics × Dofus × weapon fusion… Stat keys: `maxHp`, `might`, `area`,
  `luck`, `crit`, `cooldown`, `speed`, `projspeed`, `amount`, `regen`, `magnet`, `armor`, `duration`, `leech`,
  `reflect`, `evade`, `growth`, `pblock`, `dashCd`, `wreach`…
- `damageMob(m, dmg, spell)`: crits, numbers, sparks, death (`killMob`: drops, kamas, combo). `damagePlayer(...)`:
  armour, dodge, reflect, Phoenix.
- Beginners' help (0.95): `run.aid` = `C.beginnerAid[zone]` while that zone was never won in Normal
  (`Store.data.clearedNormal`); every monster HP passes through `Run.aidHp()`, `damagePlayer` × `aid.dmg`.
- The zone's clock drives the waves (`map.waves`, `map.events`, `map.bosses`, in minutes), scheduled elites
  (`C.elites`), ToT's door (`C.run.doorT`), the merchant (`C.merchant.t`), the Maîtres Corbacs (`C.doom.t` = 11:00).
- Delayed actions inside a run use `Run.after(sec, fn)` (run time: paused with the run, dropped with it) — never
  `setTimeout`.
- `SpellInst` (spells.js): `def` (the spell in content.json), `lv` (1–4), `p` = `spellParams(def, lv)` (`base` + the
  `lv[]` steps), `dmg()`, `cooldown()` (0.98: × `cdLateK`, the run's level, `C.run.cdLate`), `cast()` dispatching on `def.t` (projectile, orbit, zone, strike, line, melee,
  toss, bomb, detonate, beam, summon, cone, trap, leap, dash, aura, pulse, heal, buff, pioche, wheel…).
  **When a spell type starts reading a new stat, update `SYN_TYPES` in ui_armory.js** (it drives the synergy lines and
  the real values on level-up cards: `realParams` / `realDiff` / `realSummary` / `passiveReal` in ui.js; out of a run —
  the shop's cards, the Armoury's fusions — `menuSpellParams`, with a spell's own shop ends `cdShop` / `durShop` /
  `healShop`). Copies added by st.amount (Démultiplication, a relic) hit at `C.run.extraK`: `SpellInst.extraK(i)`.

## Rendering

- `Run.draw()` (render.js) draws, in order: the ground (a sliding buffer of the world tiles, `paintGround`), ground
  effects in their own layer cut by the world's decor mask (`groundFx`, `Run.underDecor`: areas stay under trees),
  shadows, monsters (`drawMob`: sheet, tint, elite / Archimonster shine, poison / bleed `drawStatus`), the player
  (`CharSprite.draw`: colour masks, hat / cape / pet / shield / weapon anchors and front layers), projectiles,
  slashes, beams, effects, particles, the scenery in front of the characters (`decorFront`, depth maps), texts, HUD.
- **PixiJS** (`pixi_render.js`, always; `?pixi=0|1` for tests): `nat(key, fn, box)` runs the same 2D code
  on `PXCtx`, a stand-in 2D context whose `drawImage` / rectangles / ellipses become PixiJS quads; the first path,
  gradient, text or filter throws `PXMiss` and that part is drawn by the real 2D code into a full-screen 2D layer or a
  small proxy box at the same place in the order. Texts, HUD and cinematics stay on the 2D canvas on top. No WebGL (or
  a lost context) → the 2D canvas draws everything. `tests/t_pixicmp.py` compares both renderers pixel by pixel. Details
  and measurements: `docs/reports/pixijs-renderer.md` (private repository).
- **Picture quality** (`QUALITY` in assets.js, Options; `?q=sd|hd|uhd|k4`): render buffer size, sheets decoded at
  0.5 / 0.75 / 1 (`img._k`), particles. Draw sheets through `Sheet.draw` / `CharSprite.draw`, which handle `_k`. Default:
  native resolution in the desktop app, 1080p on the web.
- **Visual effects** (Options, `settings.fx` full / low / min, `?fx=`): `Game.lowFx` (fewer particles, glows, sparks;
  also set by the adaptive step in `Game.adapt` under ~43 fps when the setting is Full) and `Game.minFx` (no monster
  shadows, no effects redrawn behind scenery). Gate decoration on them; never telegraphs, projectiles or ranges.
- **Camera**: `Game.zoom` = `Game.zoomBase` (from the screen size, `resize`) × the Options' distance (`settings.zoom`
  far 0.9 / normal 1 / close 1.1), eased by `Game.easeZoom` each frame. Read `Game.zoom` / `viewW` / `viewH` each frame.
- Scenery in front (`frontMask` / `decorFront`): masks cached (LRU 16) by a box snapped to 8 mask px and a foot line
  rounded to 4 units; the cut scenery is kept with its mask.
- **What PixiJS draws itself** (0.95): `PXCtx` turns `drawImage`, rectangles, filled whole ellipses and *strokes*
  (ellipses, arcs, lines, dashes: thin soft-edged quads, `PX.line` / `PX.seg`) into quads. Filled polygons, gradients,
  texts, clips and filters still fall back to a 2D layer or box sent to the GPU each frame (`PX.nat`): never put
  those in something drawn per monster or every frame — draw it once into a cached picture (`RCache.tri` / `streak` /
  `ring`, `ringAt`, `drainLine`) instead. The ground effects (`Run.underDecor`) are quads in their own container
  (`PX.groundStart` / `groundEnd`, `gfxC`), hidden under the tall scenery by the GPU (the decor mask's part on screen
  as an inverted alpha mask). `perf_probe.py --each` counts the layers / boxes per frame (`LAYERS` / `boxes`).
- **Areas on the ground**: `drawArea(ctx, x, y, r, col, a, soft)` / `RCache.area`; every area that stays on the ground —
  spell zones (`R.zones`, at `ZONE_A`), traps, the monsters' puddles (`drawHzones`) — uses the soft picture (`AREA_SOFT`:
  no outline, fill and grid fading at the edge) and `zoneRim` (particles of its element rising off its edge); the short
  impacts, rings and the telegraphs keep the hard one (`AREA_HARD`).
- **Cached pictures for what is drawn many times a frame**: `RCache` (glow, area, runes, tri, streak, ring, web, swath,
  band…), `TextCache` (texts), `NumCache` (damage numbers: one strip of characters per colour and size, drawn glyph by
  glyph). The announcements' text is placed by its ink (`annInk`, juice.js), framed by `annPanel` (render.js).
- **GPU memory**: `PX.warm` sends the run's own sheets (monsters, tiles, `run.fxNeed` = its effects) at the loading
  screen; the other effect sheets the menu preloaded stay in memory only, sent on first use.
- **Announcements** (countdown, GO!, victory, death, fusion names, banners, relic / Dofus captions, the run's end title)
  share one lettering, in juice.js: the Verdance font (0.98, `ANN_FONT` / `annFont`, assets/fonts/verdance.woff2 built by
  `tools/assets/build_verdance098.py` with the accents and punctuation it lacked; Cinzel behind it for the rest), `annGlyph`
  = one string as carved letters (an optional lime `halo`, extrusion, outline, bevel line, light top edge, gradient) with
  the palettes `ANN.cream / retro / lime` (the verdant set: the Dofus Unity and Dofus Retro logos) and `ANN.gold / ember /
  blood`, `annLayout` (per-letter layout that shrinks to fit a width), `annSheen`, `annLine` (banners), `annRule`. The
  countdown's emblem (a wreath of leaves, a glowing Dofus egg, the time as a vine) is `cdMedal` / `cdEgg`, the leaves
  `cdLeaf` / `CD_LEAVES` (events.js), GO!'s swords `goSword` (the Épée Royale du Bouftou, icons3 'go_sword'); the
  banners' frame `annPanel(…, t, style)` (`PANEL`: green; 'boss' light green with a blurred shade and glowing edge;
  'fire' for the relics: green flames, sparks). The banners' words are in Lilita (`BAN_FONT`, render.js; `annLine`'s
  `font`), the titles, names and the victory in the announcements' font. Use them for any new centre-screen message;
  keep the UI's other fonts (DofusBold, Lilita, RetroNum) for the rest.
- **Chromatic aberration** (0.98): `Run.chromaK()` (juice.js, read every frame) gives its strength of the moment, 0 to
  2.6 (from the countdown's '2' to 0.5 s after GO!, the slow motions, a boss's fall, a relic, Libération, the
  victory; less in lowFx, none in minFx); `PX.end` then draws the frame into a texture and that onto the screen through
  `pxChroma`'s filter: a lens blur — the centre sharp, the edges smeared along the radius over 9 taps weighted by colour
  (small fringes). The strength widens the blur; it never shifts the picture. Its render texture is made again at each
  new render size (`PX.caOld`: the old ones destroyed 3 frames later). Tried once on a tiny texture, left out on
  a GPU that cannot run it. Only the world gets it (no copies drawn on the 2D layer); the Canvas 2D renderer has none
  (t_pixicmp turns it off).
- **Critical summon's show** (0.98): `Run.critSeq(A)` / `critK()` (juice.js): the run at 1 % for 2 s (slowUntil / slowK:
  `slowMo` does not cut it short), confetti (`drawConfetti`), `chromaK` 2.2; the camera (real time, `critK` 0..1: 1 s in,
  2 s held, 1 s out) zooms x1.75 towards the summon (`camTarget`, render.js `zk`); one show at a time (4 s). The Arakne
  majeure's x2 is in `Run.dmgMul` while one is in `R.allies`.
- **Controller cursor** (0.98): `Nav.glide` (nav.js) draws `#navglide`, one glowing frame eased each frame towards the
  focused element's box (a light running round its edge, a pulse at each move, clipped to the list that scrolls it);
  the element keeps `.navfocus` for its own styles, its outline hidden while the frame shows (`body.navglide`).
- **HUD round buttons** (dash, moving spell, auto-pick): `hudPlate` (render.js); the pause / full-screen buttons are DOM
  (`#pausebtn`, `#fsbtn`, same look in CSS).
- Small sprites drawn every frame go through `RCache.put` (a decoded `<img>` copy: Chrome redraws downscaled canvases
  slowly at 'high' smoothing). World texts use `outlinedText` / `NumCache` (bitmaps rendered at screen size).

## Menus (DOM)

- `h(tag, attrs, ...children)` builds elements (`style: {'--var': …}` works), `btn(label, onclick, cls)`,
  `iconImg(name, size)`; `T('key', vars)` = a UI string in the current language, `L(obj)` = the current language of a
  `{fr, en, …}` object.
- Tabbed windows keep one height in landscape; their lists scroll inside (`fitNoScroll` shrinks windows that overflow a
  16:9 screen a little). Phones: see the media blocks of index.html (`t_uiaudit.py`, `t_overlap.py` check them).
- Controller / keyboard: `Nav` (nav.js), navigable elements = `Nav.SEL`; `move(dx, dy)` handles rows, columns,
  diagonals and stays inside a scrolling list. A screen that adds document listeners registers them with
  `UI.listen` / `UI.onClear` so they go with the screen.
- Frames (0.95): every `.window` has the gold bevel ring (`::before`, a mask over the border; `--bw` = its width) and
  corner rivets (`::after`); `.window.modal` (the windows over the game) a wider frame, gold diamonds on its corners, a
  title rule with a diamond, a light-up on opening and a slow sheen on the title; `.close` buttons are drawn by CSS (the
  '×' text is hidden). A window with its own coloured frame hides `::before` / `::after` (Exploit, Dark Vlad).
- **Effect colours** (0.98, Dofus 2's tooltips): a spell / weapon / characteristic line is a list of parts (`fxPart`:
  `realSummaryParts`, `realDiffParts`, `shopSpellParts`, `passiveParts`, `passiveShopParts`), drawn by `fxNodes` in the
  classes `.fx-desc` (description, orange), `.fx-eff` (damage, heals, bonuses: `FX_EFF`, green), `.fx-prop` (the other
  numbers, value bold), `.fx-neg` (a drawback), `.fx-spec` (a special effect, blue), `.fx-cond` (a condition, red); the
  colours are `--fx-*` variables for the light and dark menus (index.html). `fxText` keeps the plain text (`realSummary`…).
- Previews (`CharSprite`) belong to their screen: `UI.own` / `UI.drop`, `CharSprite.dispose` (a missing dispose leaked
  gigabytes in 0.92).

## Saves (`Store`, util.js)

`localStorage`: 3 profiles (`krosmoz-survivors-v1`, `-p2`, `-p3`) + a meta key (current profile, names). Main fields:
`kamas, owned, equip, unlocked, best, cleared, clearedHard, mastery, scrolls, spellLv, passLv, seen, kills, dofus,
relics, tot, runs, ach, board, tmaps, ttg, colors, settings{…}, lastClass/lastSex/lastMap, clearedNormal, tuto,
hardUnlocked` (0.95), and `v` = the save format
(`Store.SAVE_V`). `Store.sane` repairs damaged fields on every load / import; `Store.migrate` upgrades old formats:
**a format change = `SAVE_V + 1` and a migration step**, and refunds of removed items happen in `Game.boot`. A
forgotten migration breaks players' profiles. Export / import: Options → profile save (file) and save codes
(`Store.packSave` / `unpackSave`). Tests always use a fresh profile — never the player's saves.

## Audio

- `Audio2.play(key, vol, rate)` plays a key of `sfx_pack.mp3` (table in sounds.json); `Audio2.ui('door')`,
  `Audio2.hit(...)` (own throttle), synthesized sounds (countdown, boss arrival, dice, boosters).
- Music: `Audio2.playMusic(name, fade, { menu })`, files in `assets/audio/music/<name>.mp3`; styles classic / phonk /
  lofi (`settings.musicStyle`: in phonk / lofi every track but the menu's comes from a shuffled bag). Zones:
  `C.maps[].music` / `boss_music`. Media files carry no metadata (`tools/strip_meta.py`).

## Systems — where to look

- **Zone unlocking**: finish the previous zone with all its bosses killed in the same run (`unlockNext`); secret zones
  are `hidden` with `unlockBy` (Goultard: `'vlad_hard'`, Kwak nest: `'tot'`).
- **Bosses**: `spawnBoss`, `updateBoss`, bosses.js; bars `drawBossBar`. **Scheduled elites**: `updateElites` (extras.js).
- **Ganymède's scenes** (tutorials of the first three zones, Hard mode unlocked): `C.gany`, `UI.ganyScene` (ui_events.js),
  started from main.js startRun / runOver; Hard is locked until `C.gany.unlockHard` is won (`Store.hardOk()`).
- **Relics, Dofus, Archimonsters, chests, TTG boosters, Musha's treasure maps, the skin merchant, ToT's door / Tofuzmo,
  Coffre Animé, the Minotoror trapdoor, Maîtres Corbacs, Endless, Hard**: extras.js / events.js (`C.<system>`).
- **Level-up**: `upgradeOptions`, `UI.levelUpMenu`, card fitting `fitCards`; Banish / Skip once a run.
- **Shop**: spells, characteristics (`passLv`), weapon masteries, scrolls, global spells, skins, shields.
- **Monster states**: poison `poisonUntil`, bleed `bleedUntil`, burn `burnUntil/burnDps`, slow, stun, confusion.
  `Run.poisonCloud` = a short zone (`z.dose`) that poisons each monster in it once (the Piège Empoisonné's gas);
  `Run.poisonPuff` = the same at a poisoned spell's single hit (0.25 s, `drawPoisonPuff`): no spell poisons one monster
  directly any more (weapons' `poisonW` still do).
- **Blows on the character**: `damagePlayer(dmg, src, area)`; `area` = a ground area (telegraphs, hostile puddles, a
  boss's spin) — the only blows that reach an invisible Sram (`invisUntil`); projectiles (lobs too) and contact miss.
- **Achievements**: progress.js (`Prog.add` at hook points, `Prog.value` for computed ones), each with its own picture.

## Debug URL parameters

`?autostart=1&fresh=1&cls=iop&sex=0&map=astrub` starts a run at once on a fresh profile. Others (see `Game.boot` and
`Game.debug` uses): `t=150` (start time, s), `hard=1`, `infinite=1`, `weapon=epee`, `weapon=kaiser&fusion=force`,
`spells=fouet:4,prouts` (spells at a level), `lv=`, `hat=16_7&cape=17_48&pet=18_1&shield=…`, `tot=1`, `portal=1`,
`tmap=1|<zone>`, `drago=1`, `manuel=1`, `cd=1` (keep the countdown with autostart), `q=sd|hd|uhd|k4`, `pixi=0|1`,
`kwak=1`, `tofu=1`, `bot=1`, `nodraw=1`, `speed=`, `fx=full|low|min`, `gany=<zone|hard>` (a Ganymède scene), `tuto=1` (the zone tutorial in an autostart run).

The test code **GODMODE** (Options > save code, `Store.godMode`) gives the current profile everything: every zone open
and won (secret ones, Difficile), every shop line at its top, every look, Dofus, relic, achievement, soul, TTG card,
unique weapon and fusion, the bestiary seen, 9 999 999 kamas. It adds, it takes nothing away.

## Known traps (already paid for)

- `Audio2.playMusic` compares a logical name (style + name): set `musicName = null` to force a replay.
- Run-time timers: `Run.after`, never `setTimeout` (they ran during the pause and after the run).
- Clocks that advance per drawn frame run faster on 144 Hz screens and during the pause: advance them in updates.
- A CSS `filter` on an element in `preserve-3d` flattens it (the TTG card showed its back mirrored).
- Tests that start a run must wait for the countdown (the clock is frozen 3.3 s). Without `autostart` the loading
  screen waits for its Play button (`.load-play`); with it, Ganymède's tutorial only shows with `?tuto=1`.
- Chrome draws a small canvas *downscaled* at 'high' smoothing 3–15× slower than an `<img>`; at scale 1 there is no
  difference. Many small draws are cheapest from one atlas. Measure with `tools/checks/bench_draw.py` before changing.
